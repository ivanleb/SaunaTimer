«Сауна Пульс» — приложение-компаньон для часов на Wear OS. Часы засекают время заходов в сауну и записывают пульс, а телефон хранит историю.

<b>Возможности</b>
<ul>
<li>Список всех заходов: длительность, максимальный и средний пульс</li>
<li>График пульса для каждого захода с отмеченными лимитами</li>
<li>Сравнение: несколько графиков поверх друг друга и таблица рядом</li>
<li>Отправка одного или всех заходов в виде файла CSV</li>
<li>Настройка лимитов времени и пульса, синхронизация с часами</li>
<li>Удаление ошибочно записанных заходов — и на телефоне, и на часах</li>
<li>Русский и английский языки</li>
</ul>

<b>Синхронизация без облака</b>
После каждого захода часы отправляют его прямо на телефон по Bluetooth. Выберите часы один раз в настройках, и на Android 12 и новее заходы будут приходить в фоне, даже когда приложение закрыто. Пока телефона нет рядом, заходы ждут на часах.

<b>Конфиденциальность</b>
Ваши данные остаются на часах и телефоне. У приложений нет доступа в интернет, нет аккаунтов, рекламы и аналитики, облачное резервное копирование отключено. Данные покидают устройства, только когда вы сами отправляете CSV.

<b>Нужно также приложение для часов</b>
Заходы записывает приложение для часов («Сауна Пульс» для Wear OS). У F-Droid нет клиента для часов, поэтому установите APK для часов со страницы GitHub Releases проекта; инструкция есть в README.

<b>Безопасность</b>
«Сауна Пульс» — не медицинское устройство. Часы могут измерять пульс неточно, особенно в жаре и на влажной коже. Выходите из сауны, как только почувствуете недомогание, что бы ни показывало приложение.

Разработано и проверено на Samsung Galaxy Watch4. Другие часы на Wear OS 3+ с датчиком пульса тоже должны работать.
